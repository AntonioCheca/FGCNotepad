Scenario Table Spreadsheet Behavior Gap Audit (Current vs Target)

Prioritized Top 10 Gaps

| Behavior | Current State | Missing Capability | Severity (High/Med/Low) | Suggested First Fix |
|---|---|---|---|---|
| Rectangular range selection (Shift+Arrow / drag) | Only per-input focus exists; no grid selection model or selected range state in table UI (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx:375`, `frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx:386`) | Spreadsheet range selection, anchor/focus cells, range highlight, multi-cell operations | High | Add a central `selection` state (anchor + active + range bounds) at table level and render selected styling in cells before any clipboard work |
| Multi-cell paste (TSV/CSV blocks) | No `onPaste` handling in table/grid components; paste falls back to single input behavior (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx`) | Parse tab/newline blocks and apply rectangular writes from active cell | High | Implement grid-level paste handler that parses TSV first, CSV fallback, then batch-apply by coordinates |
| Navigation/edit mode separation | Cells are always editable inputs; arrow keys move focus between inputs (not caret) when neighbors exist (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx:386`) | Spreadsheet dual mode: navigation mode vs in-cell edit mode | High | Introduce `mode: 'nav' | 'edit'`; Enter/F2 starts edit, Escape cancels, arrow keys navigate only in nav mode |
| Tab / Shift+Tab / Enter / Shift+Enter traversal | Only arrow key handling is custom; no custom Tab/Enter variants (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx:386`) | Deterministic spreadsheet traversal across rows/cols, including shift variants and edge wrapping rules | High | Add a keymap dispatcher in one place with explicit traversal rules and tests for boundary behavior |
| Single source of truth for focused cell | `refMatrix` is created inside each cell component, so each cell tracks only itself (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx:377`) | Global focus registry and stable coordinate-based focus management | High | Move ref matrix/focus map to parent table component (or hook) and pass coord handlers into cell renderer |
| Clipboard copy/cut for ranges | No copy/cut serialization for selected cells; no selected-range abstraction (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx`) | Copy selected block as TSV; cut with clear policy for editable vs computed cells | Med | After range model lands, add `onCopy/onCut` handlers to serialize selected rectangle to clipboard |
| Validation feedback UX | Invalid numeric/frequency input is mostly ignored/silently constrained in service; no per-cell error state or user message (`frontend/services/ScenarioTableService.tsx:107`, `frontend/services/ScenarioTableService.tsx:123`) | Visible validation status (invalid, partial, out-of-range), recoverable inline feedback | Med | Add cell-level validation map keyed by coordinates + frequency keys; show visual error state and non-blocking helper text |
| Type consistency for cell values | `values` typed as `number[][]`, but temporary strings are written using `as any` (`frontend/services/ScenarioTableService.tsx:110`, `frontend/hooks/useScenarioTableState.tsx:7`) | Explicit edit buffer type (`CellValue = number | '' | '-' | formula`) with parse lifecycle | High | Introduce typed cell model and split committed numeric value from editing draft text |
| Full matrix state serialization parity | Node export omits `rowFrequencies`, `columnFrequencies`, `expectedValue`, while import expects them (`frontend/src/components/lexical/ScenarioTableNode.tsx:81`, `frontend/src/components/lexical/ScenarioTableNode.tsx:92`) | Lossless round-trip for all matrix state (including later computed/cell metadata) | High | Align export/import schema now; define versioned serialized type for future computed/reference metadata |
| Mobile interaction model | Interaction assumes keyboard-heavy desktop flow; no touch selection handles or mobile-specific edit affordances; dense 60px inputs (`frontend/src/components/lexical/ScenarioTable/ScenarioTable.tsx:416`) | Practical mobile UX for selecting/editing/pasting within constrained viewport | Med | Define mobile fallback MVP: single-cell edit + toolbar navigation buttons; postpone drag-range selection on touch |

Do First (MVP)

1. Central grid state model: active cell + selection rectangle + nav/edit mode.
2. Keyboard keymap engine for arrows/tab/enter/shift variants in nav mode.
3. Grid-level paste handler for TSV/CSV rectangular blocks.
4. Global focus registry owned by parent table (not per-cell local refs).
5. Typed cell model separating draft text from committed numeric values.
6. Serialization parity for rows/cols/values/frequencies/EV so state is not dropped.

Do Later (Post-MVP)

1. Range copy/cut + clipboard export normalization.
2. Rich validation UI (inline errors, aggregate warnings, frequency sum indicators).
3. Mobile-enhanced gestures (touch drag selection handles, long-press range start).
4. Computed/non-editable cells, cross-matrix references, and cycle-aware evaluation engine.
