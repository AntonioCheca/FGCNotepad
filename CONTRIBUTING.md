# Contributing

Thanks for helping improve FGCNotepad.

## Workflow

1. Fork the repository.
2. Create a new branch in your fork.
3. Make your changes on that branch.
4. Open a pull request against the main repository.

## Pull Requests

Keep pull requests focused, clearly described, and ready for review. Include enough context for reviewers to understand what changed and why.

Before opening a pull request, run:

```bash
make check
```

This runs the project checks expected before review, including tests, backend validation, frontend linting, frontend type checks, and React Doctor.
