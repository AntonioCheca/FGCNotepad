Matrix Editor Manual QA Protocol v0 (MVP + Near-Future)

Purpose
- Validate spreadsheet-like matrix editor behavior for forum/Lexical embedding.
- Cover MVP and near-future areas: keyboard, selection, paste, validation, readonly/computed, mobile.

Test data set (FG use cases)
- Scenario A (RPS baseline)
  - Rows (P1): `Throw`, `Shimmy`, `Meaty`
  - Cols (P2): `Tech`, `Backdash`, `DP`
  - Payoffs:
    - Throw: 2, -3, -8
    - Shimmy: 6, 4, -2
    - Meaty: 3, 1, -10
- Scenario B (anti-air risk)
  - Rows: `2H`, `Air-to-Air`, `Block`
  - Cols: `Jump-in`, `Empty Jump`, `Divekick`
  - Payoffs:
    - 5, -1, -4
    - 3, 0, 2
    - -2, 1, -1
- Frequencies seed
  - Row freq: `0.33, 0.34, 0.33`
  - Col freq: `0.40, 0.35, 0.25`
- Paste block sample TSV
  - `5\t-2\t7\n1\t0\t-4`
- Paste block sample CSV
  - `3,2,-1\n-5,4,6`

--------------------------------------------------
1) Test Matrix (Grouped)
--------------------------------------------------

Keyboard Navigation
- KN-01: Arrow keys move focus by one cell in nav mode.
- KN-02: Tab/Shift+Tab traverse left-right without leaving grid bounds.
- KN-03: Enter/Shift+Enter traverse down-up without leaving grid bounds.
- KN-04: Esc in nav mode collapses multi-cell selection to focused cell.
- KN-05: F2 enters edit mode only on editable cell.
- KN-06: Printable key enters edit mode and starts draft.
- KN-07: In edit mode, Esc cancels draft and restores original committed value.
- KN-08: In edit mode, Tab commits and moves to next cell.

Selection
- SEL-01: Single click sets active+focused+single-cell selection.
- SEL-02: Shift+Arrow expands rectangular selection from active cell.
- SEL-03: Mouse drag creates rectangular range and finalizes on mouse-up.
- SEL-04: Selection highlight remains correct when horizontally scrolled.
- SEL-05: Selection across mixed editable/readonly cells remains rectangular.

Paste
- PST-01: TSV block pastes from active anchor correctly.
- PST-02: CSV fallback works when no tabs present.
- PST-03: Trailing newline is ignored (no phantom row).
- PST-04: Overflow cells clip at grid edge; in-bounds cells still apply.
- PST-05: Partial paste warning appears for skipped cells.
- PST-06: One undo reverts entire paste operation.

Validation
- VAL-01: Draft-invalid text allowed during typing (no blocking).
- VAL-02: Valid draft commits to typed numeric output.
- VAL-03: Frequency out-of-range shows error state (`<0` or `>1`).
- VAL-04: Invalid commit does not silently coerce to `0`.
- VAL-05: Paste invalid tokens skip per-cell and report summary.

Readonly / Computed Behavior
- ROC-01: Computed readonly cells can be focused but not edited.
- ROC-02: Delete/backspace on mixed selection mutates only editable cells.
- ROC-03: Readonly cells remain unchanged after paste over mixed selection.
- ROC-04: Computed status badge/message shown for approximate/capped states.
- ROC-05: Manual override cells display effective value and override indicator.

Mobile
- MOB-01: Tap selects active cell reliably.
- MOB-02: Single-cell edit commit/cancel works with on-screen keyboard.
- MOB-03: Horizontal scroll + sticky zones remain readable.
- MOB-04: Touch targets for controls meet minimum usability.
- MOB-05: Fallback compact mode auto-applies on narrow viewport.

--------------------------------------------------
2) Must-Pass Smoke Suite (20 checks max)
--------------------------------------------------

1. Load existing old post containing scenario table without crash.
2. Arrow navigation works across 3x3 matrix body.
3. Tab/Shift+Tab traversal works in-row.
4. Enter/Shift+Enter traversal works in-column.
5. Enter edit mode, type `-`, continue to `-3`, commit success.
6. Esc cancels edit and restores previous value.
7. Single click updates active/focused cell.
8. Drag-select 2x3 range and highlight is rectangular.
9. Delete on selected editable range clears only editable cells.
10. TSV 2x2 paste writes correct values from anchor.
11. CSV 2x2 paste fallback works correctly.
12. Paste overflow clips and preserves in-bounds writes.
13. Readonly/computed target skips mutation during paste.
14. Partial paste warning summary shown (applied/skipped counts).
15. Frequency cell rejects commit above 1 with visible invalid state.
16. EV display updates after committed numeric changes.
17. Sticky header/first column/frequency row remain visible during scroll.
18. One undo reverts full multi-cell paste.
19. Mobile tap-edit-commit cycle works on one cell.
20. Save/reload round-trip preserves rows/cols/values/frequencies/EV.

Smoke pass criteria
- 20/20 required for release candidate; no High severity open defects.

--------------------------------------------------
3) Edge-Case Suite (>=25 checks)
--------------------------------------------------

Keyboard + mode edge cases
1. Shift+Tab at left boundary does not move out-of-bounds.
2. Enter at bottom boundary clamps per policy.
3. Arrow in edit mode moves caret (not grid) by default.
4. Printable key on multi-selection collapses to focused cell before edit.
5. Esc in nav mode from large selection collapses without mutation.

Selection edge cases
6. Drag selection starting in readonly cell ending in editable cells.
7. Reverse drag (bottom-right to top-left) normalizes rectangle correctly.
8. Selection persistence after scroll jump and refocus.
9. Selection across sticky boundary (first column + body) remains aligned.
10. Selection after row/column move still targets intended coordinates.

Paste parsing edge cases
11. TSV with blank interior row preserves row spacing.
12. CSV with quoted comma (`"12,5"`) handled per policy.
13. Malformed CSV quote hard-fails with no mutation.
14. TSV with trailing tab creates empty final field.
15. Single token paste (`42`) behaves as single-cell overwrite.

Paste placement/conflict edge cases
16. Paste over mixed readonly/editable range applies editable subset only.
17. Paste at bottom-right corner clips correctly both directions.
18. Paste with invalid + readonly + overflow mixes reports accurate counts.
19. Paste into frequency row applies frequency validation rules.
20. Undo after partial paste reverts all applied cells in one action.

Validation edge cases
21. Draft token `0.` remains allowed while editing.
22. Draft token `--1` shows invalid state but typing continues.
23. Blur with invalid draft keeps visible invalid state, no silent conversion.
24. Large negative payoff (e.g., `-999`) commits if type policy allows.
25. NaN/Infinity from computed formula path surfaces eval error state.

Readonly/computed/cycle edge cases
26. Computed cyclic cell with capped iterations shows `capped approximation` status.
27. Unstable loop state (`diverging`) shows warning and keeps last finite value.
28. Missing dependency marks cell `dependency_missing` without editor crash.
29. Override cell keeps override effective value when base computed changes.
30. Deleting selection containing override cells follows override-clear policy only.

Mobile edge cases
31. Narrow viewport auto-compact mode keeps core cells operable.
32. Touch scroll does not accidentally trigger drag-range when not supported.
33. On-screen keyboard open does not hide active-cell editor entirely.

Serialization edge cases
34. Load legacy implicit-v1 payload without explicit version.
35. Unknown future version loads degraded readonly view with preserved raw fields.

--------------------------------------------------
5) Release Sign-off Checklist
--------------------------------------------------

Functional quality
- [ ] Smoke suite passed 20/20.
- [ ] Edge suite executed with documented results.
- [ ] No open Critical/High defects.
- [ ] Known Medium defects have approved workaround + owner.

Data safety
- [ ] Legacy load path verified on representative old posts.
- [ ] Save/reload round-trip shows no matrix metadata loss.
- [ ] Partial parse/paste failures do not corrupt existing data.

Interaction quality
- [ ] Keyboard nav/edit parity meets spec.
- [ ] Selection behavior consistent under scroll and sticky regions.
- [ ] Readonly/computed mutation guards confirmed.

Performance + mobile
- [ ] Key interaction latency within agreed budgets on target test matrices.
- [ ] Mobile fallback flow validated (tap/edit/commit/navigation).

Operational readiness
- [ ] QA report archived with build id, date, owner.
- [ ] Open issues triaged with severity and milestone.
- [ ] Product/design/dev sign-off recorded.
